🔧 Variables

❓ What are variables and how do they work?

Variables are placeholders in your prompt that you can fill in later.

Example:

Create a {{style}} photograph of {{subject}} using {{camera}}.

How it works:

  1. Click "Add Variable" button above
  2. Enter variable name (e.g., "subject", "style", "camera")
  3. Add description (optional - helps you remember what it's for)
  4. Variables appear in your prompt as {{variableName}}
  5. Fill in the values when you're ready to use the prompt

Why use variables?

  • Reusable: Create one prompt template, use it many times
  • Consistent: Same structure every time, just change the details
  • Faster: No need to rewrite the whole prompt

💡 Pro Tip: Templates already have variables built-in! When you select a template, its variables automatically appear here.
